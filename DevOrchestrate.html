D DEVORCHESTRATE02 / Planner + plan anatomy

From spec.md to executable blueprint

The Planner makes the design actionable.

01 · Discover the workspace

Read spec.md; inspect architecture, existing files, method signatures, dependencies and tests.

02 · Prioritize safe reuse

Identify reusable classes and utilities; justify every new component or refactor.

03 · Generate only real choices

PlanA.md to PlanZ.md if warranted; one plan if that is the only sound option.

04 · Compare and wait

Document design, code changes, phases, risks, rollback, merits/demerits and AC coverage. Human selects.
